# Client content checklist

Collect and verify these before the production launch. All current catalogue data, contact information and illustrations are samples.

## Business
- [ ] Exact business / legal name
- [ ] Logo and permitted brand assets
- [ ] Tagline and approved shop description
- [ ] WhatsApp number with country code
- [ ] Phone and email
- [ ] Exact shop address and Google Maps pin
- [ ] Opening hours and closure days
- [ ] Facebook, Instagram, TikTok and YouTube URLs
- [ ] Ownership / access for desired domain and DNS
- [ ] GitHub and Vercel owner accounts

## Each product
- [ ] Category and brand
- [ ] Product name and exact model
- [ ] Current price and whether it should be displayed
- [ ] Genuine old price / discount evidence if applicable
- [ ] Stock status, availability and dates
- [ ] Available variants and any price differences
- [ ] Approved description, features and specifications
- [ ] Applicable warranty and service process
- [ ] Actual product and gallery images with permission
- [ ] Safety / electrical / installation guidance

## Store
- [ ] Exterior photos
- [ ] Interior photos
- [ ] Team photo if desired

## Policies
- [ ] Delivery areas and charges
- [ ] Delivery timing and coordination
- [ ] Pickup arrangements and policy
- [ ] Warranty terms and service contacts
- [ ] Return / exchange policy
- [ ] Privacy practices, retention and contact process
- [ ] Reviewed terms and FAQ answers

## Launch approval
- [ ] Replace all placeholder identities, contact details and map/social links
- [ ] Verify every demo listing; remove sampleData only after verification
- [ ] Replace illustrative shop/product images
- [ ] Review privacy and terms starter copy
- [ ] Confirm siteUrl matches actual production domain
- [ ] Disable isDemo only when content is approved
- [ ] Enable publishStructuredData only for verified content
- [ ] Verify GitHub → Vercel automatic main-branch deployments
- [ ] Test WhatsApp number, message, quantity and variants on actual phones
